# Self-Learning Platforms & Tech Communities 🧠

The best resources to become job-ready, all with practical skills and project focus.

---

## 🌍 MOOCs, Course Platforms

- [Coursera](https://www.coursera.org/) — *Top global universities, skills to certificates, career focus.*
- [edX](https://www.edx.org/) — *Harvard/MIT/IITs—project-based learning for every field.*
- [Udemy](https://www.udemy.com/) — *Diverse catalog—often free via coupons.*
- [freeCodeCamp](https://www.freecodecamp.org/) — *Build by coding; create real projects, get verified certifications.*
- [Khan Academy](https://www.khanacademy.org/) — *Intuitive visuals, math, logic, and CS.*
- [Codecademy](https://www.codecademy.com/) — *Guided, interactive, all major languages and web basics.*
- [SoloLearn](https://www.sololearn.com/) — *Micro-lessons for learning on your mobile.*
- [NPTEL](https://nptel.ac.in/) — *Indian institute video lectures—great for core concepts.*
- [Stanford Online](https://online.stanford.edu/courses) — *World-class research-driven courses in tech and science.*
- [Harvard Online Learning](https://online-learning.harvard.edu/catalog/free) — *Broad selection of free professional growth courses.*
- [Saylor Academy](https://www.saylor.org/) — *Self-paced courses and college credit options.*
- [Google Digital Garage](https://grow.google/intl/en_in/courses/) — *Digital marketing, business, beginner tech skills.*
- [Learn with Google AI](https://ai.google/education/) — *Free, practical AI/ML short courses and guides.*

## 👥 Coding & Practice Sites

- [GitHub Learning Lab](https://lab.github.com/) — *Hands-on tutorials on real-world git and GitHub workflows.*
- [HackerRank](https://www.hackerrank.com/domains/tutorials/10-days-of-javascript) — *Coding contests, interview Qs, and learning tracks.*
- [LeetCode](https://leetcode.com/explore/) — *The most-used interview prep problem bank.*
- [Codewars](https://www.codewars.com/) — *Kata-based challenge site for practicing and upskilling.*
- [Codeforces](https://codeforces.com/) — *Live contests to improve problem-solving speed.*
- [Project Euler](https://projecteuler.net/) — *Algorithmic and math-driven project challenges.*
- [Exercism](https://exercism.org/) — *Mentor-reviewed exercises in dozens of languages.*
- [Coderbyte](https://coderbyte.com/) — *Practice, interview and competitive programming tests.*
