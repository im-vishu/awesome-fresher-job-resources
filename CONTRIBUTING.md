# Contributing to Awesome Fresher Job Resources

Thank you for making this list better!  
Your suggestions, corrections, and stories help job seekers all over the world.

## How to Contribute

- **Add a new resource:**  
  - Open a pull request (PR).
  - Place your resource in the correct section of the README.
  - Add a short, helpful description after the link.
  - Use optional tags (example: `Beginner-friendly`, `Women-in-tech`, `India`, `Remote`, etc.) for clarity.

- **Report or fix broken/outdated links:**  
  - Submit a PR with the fix — or open an issue if you found a dead link but don't know a replacement.

- **Share your success story:**  
  - PR your story to the "Success Stories" section or start a [Discussion](https://github.com/im-vishu/awesome-fresher-job-resources/discussions).

- **Translations/Localizations:**  
  - Volunteer to translate sections of the README to other languages. Add your translation at the end under a heading with the language name (e.g., `## हिंदी (Hindi)`).

## Guidelines

- List **free**, reputable, and high-quality resources only.
- Keep entries short and descriptive.
- No self-promotion, spam, or unrelated content.
- Check that links are valid and not duplicates.
- Tag resources where relevant (`Beginner-friendly`, `Global`, etc.).
- For larger changes or new sections, [open an issue](https://github.com/im-vishu/awesome-fresher-job-resources/issues) to discuss first.

## Format Example

```markdown
- [Resource Name](https://example.com/) – Short description. _(Beginner-friendly, Global)_
```

Thanks for helping make this resource awesome for everyone!
